# Лабораторная работа №4: Предприниматель и стартапер

**Автор:** Пашко Святослав

## 📝 Описание проекта
Данный проект представляет собой одностраничный сайт-портфолио предпринимателя с аналитическим дашбордом стартапа. Сайт включает в себя информацию о ценностях бизнеса, идеи для стартапов, ключевые метрики (MAU, LTV, CAC) и форму обратной связи. 

Также на странице реализован интерактивный скрипт (Вариант 16), который анализирует массив с дневной выручкой стартапа, вычисляет статистику и выводит результаты пользователю.

## 🛠 Используемые технологии
*   **HTML5** — семантическая верстка, формы, встроенные элементы (`meter`).
*   **CSS3** — переменные (`:root`), Flexbox, CSS Grid, адаптивная верстка (медиа-запросы), анимации и hover-эффекты.
*   **JavaScript (Vanilla JS)** — работа с DOM (через `prompt` и `alert`), массивы, циклы, условные конструкции и функции.

## 📁 Структура проекта
*   `index.html` — основной HTML-файл страницы (содержит разметку и подключение стилей/скриптов).
*   `css/style.css` — файл со стилями (оформление карточек, сеток, кнопок и адаптивность).
*   `js/script.js` — скрипт с логикой аналитики выручки.

## ⚙️ Функционал JavaScript (Вариант 16)
Скрипт выполняет следующие задачи:
1.  Запрашивает имя пользователя через `prompt` и приветствует его через `alert`.
2.  Хранит массив из 7 чисел (дневная выручка в рублях).
3.  **Функции:**
    *   `calculateSum(arr)` — подсчет общей суммы выручки.
    *   `findMax(arr)` — поиск максимального значения.
    *   `filterRevenue(arr, threshold)` — фильтрация дней с выручкой выше заданного порога.
4.  **Аналитика:**
    *   Считает количество дней с выручкой > 10 000 ₽.
    *   Считает количество и долю дней с низкой выручкой (≤ 3 000 ₽).
    *   Вычисляет среднюю дневную выручку.
5.  **Вывод:** 
    *   Общая выручка и количество успешных дней выводятся через `alert`.
    *   Статистика по низкой выручке и предупреждение (если средняя выручка < 5000 ₽) выводятся в `console.log` / `console.warn`.
